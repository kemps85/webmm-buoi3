# Góc Sao - bài tập Web Multimedia, Buổi 3

Website 5 trang của CLB Thiên văn sinh viên "Góc Sao" (CLB hư cấu).
Sinh viên: Bảo Quý Phát, MSSV 24667151, IUH.

- Bản xuất bản thử (GitHub Pages, HTTPS): https://kemps85.github.io/webmm-buoi3/
- Trang: index.html, thu-vien.html, bai-viet.html, lien-he.html, so-do-site.html
- Media: ảnh, video, âm thanh đều tự tạo (Python + ffmpeg), nguồn và giấy phép từng file ở `media/README.md`
- Không dùng framework, chỉ HTML + 1 tệp `css/site.css` + `js/player.js` (41 dòng) + `js/xemthem.js`

Chạy thử local: `python -m http.server` trong thư mục này (hoặc mở thẳng index.html).
